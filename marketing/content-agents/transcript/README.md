# Transcripts

Save the transcripts of three to five calls here before step 1, one file per call, each named with the date of the call, such as `2026-10-06-podcast.txt`.

Calls your team already recorded, such as a founder's podcast, a webinar, a demo or a customer call. Take customer names out first, or let step 1 swap them for roles. Auto captions are fine, and so are speaker labels and filler. The one real problem is audio so bad whole sentences are lost, and that's a recording fix.

Every week, add the new calls here with the date in each name. The `content-research` skill reads any call that isn't in `ideas.md` yet.
