# Maven session kits

Every build from Catalyst's live Maven sessions, in Claude Cowork and Claude Code, with no code to write. Each folder is one session. It holds the prompts in the order they ran, the templates, and a finished version to compare yours against.

## Use a kit

1. Open the folder for your session below and read its `README.md`, right here in the browser.
2. Get the folder onto your computer. Click Code at the top of this page, then Download ZIP, or clone the repo if you use git.
3. Open that session's folder in Claude Cowork, or in Claude Code, and follow its `BUILD_STEPS.md`.
