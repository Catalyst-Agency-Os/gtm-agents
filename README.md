# GTM Agents

AI agents for the work sales, marketing, RevOps and GTM teams repeat every week. Each one was built live in a Catalyst session in Claude Cowork or Claude Code, with no code to write. Every folder holds the prompts in the order they ran, the templates, and a finished version to compare yours against.

## Set one up

1. Open an agent's folder below and read its `README.md`, right here in the browser.
2. Get it onto your computer. Click Code at the top of this page, then Download ZIP, or clone the repo if you use git.
3. Open the agent's folder in Claude Cowork or Claude Code and follow its `BUILD_STEPS.md`.
